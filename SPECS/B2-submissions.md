# Spec B2 — Submissions, decisions, comments, CSV, group mail

Read `SPECS/B-shared.md` first. Prototype: `design/Submissions.dc.html`. Your files per ownership map. You also own `src/lib/decisions.ts` (shared status-change engine) and `src/lib/csv.ts` (used by other tracks).

## `/app/submissions`

Port the screen in full:
1. **Table**: columns ☑ / ID (SUB-seq) / SESSION (title + speakers + "via <form>" tag for non-CFP) / TRACK (dot+name) / FORMAT / SCORE (avg + done/total from evaluations) / STATUS badge / SUBMITTED. Status chip row with live counts (All + each status with >0; keep zero-count statuses hidden except All). Form + track selects, search (title+speaker, debounced server query or client filter — client fine ≤500 rows, server search param beyond). Score column header toggles sort. Row click → drawer. Checkbox select; header checkbox = select-all-filtered.
2. **Bulk bar** (dark) on selection: count, Accept…/Waitlist…/Decline… (open decision modal with all selected), Send email (group mail composer), Export selection (CSV of selected), Clear.
3. **Empty state** for genuinely 0 submissions: copy from prototype incl. copy-link button with the real form URL and "Import from CSV instead".
4. **Drawer** (520px, slide-in): status badge, title, Accept/Waitlist/Decline buttons, track/format/level cards, ABSTRACT, **ANSWERS**: render all custom-field answers from the pinned form version (label + value; files as download rows with icon/size — real `files` rows), SPEAKERS cards (avatar initials, name, email, bio, headshot thumb if present), EVALUATION block (avg + per-criterion bars + "N of M evaluations in" — from evaluations joined via plans), INTERNAL COMMENTS (team-only; input with Enter/Post; @-mention: typeahead over org members on "@", mention → email notification to mentioned member linking the submission), ACTIVITY LOG (real rows, newest last as prototype).
5. **Decision modal** (the emotional centerpiece — match prototype copy exactly): recipient list ("CHECK THIS LIST. THIS EMAIL CANNOT BE UNSENT."), per-recipient optional feedback inputs on decline (merged as `{{individual_feedback}}`, omitted cleanly when blank), subject/body editable per send (prefilled from event's email_templates accept/decline/waitlist), variables hint, accept-only "Request confirmation" checkbox (default on; when on, `{{confirmation_link}}` resolves per recipient; when off, accept sets status accepted and the email omits the link), summary line, confirm button "Send N emails & update status".
6. **`src/lib/decisions.ts`**: `applyDecision(env, {eventId, ids, decision, subject, body, perRecipientFeedback, requestConfirmation, actorName})` → per submission: set status, on accept create session via `sessions-core.createSessionFromSubmission` (skip if session exists), render+queue email per FIRST speaker (owner speaker) with vars, activity log entries, email log rows. Returns counts. Waitlist promotion = just run accept later (identical flow).
7. **Deep-link params**: `?open=<subId>` auto-opens drawer; `&action=accept|decline|waitlist` also opens the modal. (Evaluation track links here.)
8. **CSV export**: current filter or selection; columns: id, title, status, track, format, level, speakers (name <email> ; …), score, evalDone, evalTotal, submitted_at, form + one column per custom field (label). Proper quoting (`csv.ts`: `toCsv(rows)` + `parseCsv(text)` — real quoted-field parser, no naive split).
9. **CSV import**: dialog: file input → parse client-side → mapping step (each CSV column → form field / speaker name / speaker email / status / ignore) → preview count → POST rows; creates submissions (status from column or 'submitted'), speakers, activity "imported from CSV". Unknown statuses → submitted.
10. **Group mail composer** (from bulk bar + reused by empty "Send email"): modal with recipient summary (N speakers of selected submissions), template select (event templates + blank), subject/body editable, variables hint, per-recipient preview toggle (first recipient sample), send → queue emails + log + toast.

Definition of done per B-shared. Curl-test: list page 200; decision API on sandbox subs changes status + writes emails/activity; CSV export returns valid CSV; comment POST works.
