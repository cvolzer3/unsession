## `src/lib/tasks.ts`

- `generateTasksOnTrigger(env, {submissionId, trigger: 'acceptance'|'confirmation'})`: find event's active templates with that trigger whose clauses match the submission (Track/Format/Level via answers/taxonomies; 'Form answer' clause: substring match "Field label = value" against answers — keep the prototype's loose semantics), stamp instances: speaker-target → one per submission speaker's speaker_profile (create profiles from submission_speakers if missing, slugified), session-target → one for the submission's session. Compute due_date from due_json (after=assignment+N days; before=event start−N; abs). Skip if an open instance for same template+target exists. Activity log each. Assignment email = digest per speaker (one email listing new tasks, template task_nag subject tweak) — keep simple: one email per generation batch per speaker.
- Withdrawal hook `cancelOpenTasks(env, submissionId)` (called by portal withdraw).
- Status transitions: checkbox toggle → done; file upload → done or pending_review (template review flag); form submit → done; profile type auto-completes when profile has name+bio+headshot (check on profile save).
