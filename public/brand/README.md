# Unsession brand assets

The mark is an open **U** assembled from six square agenda blocks. The missing
upper-right block is the useful bit: it reads as an open session slot, an
unfinished program, and the “un-” in Unsession without adding a second symbol.

## Files

- `unsession-logo.svg` — primary horizontal lockup, indigo mark + ink wordmark.
- `unsession-mark.svg` — icon-only mark on a transparent background.
- `unsession-watermark.svg` — single-color lockup at 8% opacity for overlays.
- Matching PNG exports are included for tools that cannot use SVG.
- `unsession-readme.png` — warm-paper lockup card used by the GitHub README.

## Usage

- Primary indigo: `#4c5fd5`
- Wordmark ink: `#16171d`
- Preferred light background: `#faf8f5` or white
- Keep clear space around the logo equal to one square from the mark.
- Use the full lockup at 112 px wide or larger. Below that, use the mark alone.
- Do not round the blocks, close the open slot, add shadows, or recolor blocks
  individually. The geometry is meant to echo Unsession's square, technical UI.

The wordmark is Space Grotesk Bold converted to vector paths, so the SVG does
not depend on an installed font.
